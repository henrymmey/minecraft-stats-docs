# HM Stats Documentation

Operator-first documentation for the HM Stats platform.

The primary audience is **clan and community administrators**, not developers.

## Start here

The recommended reading order for a new installation is:

1. [Installation](/installation/)
2. [Domain & HTTPS](/self-hosting/domain)
3. [OIDC administrator login](/self-hosting/oidc)
4. [Dashboard](/dashboard/)
5. [API Keys](/dashboard/api-keys)
6. [Servers & Seasons](/dashboard/servers-seasons)
7. [Client installation & configuration](/client/configuration)
8. [Troubleshooting](/troubleshooting/)

## Documentation responsibilities

This repository is the public documentation and API contract source for:

- installation and self-hosting
- domain/TLS and OIDC configuration
- dashboard administration
- client installation and configuration
- security and operational guidance
- REST API reference
- OpenAPI v1
- contributor/development notes
